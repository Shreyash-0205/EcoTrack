# 2. Abstract

Rapid urbanization and expanding population densities across Greater Mumbai and Indian metropolitan centers have led to unprecedented solid waste challenges. Mismanaged garbage hotspots cause environmental pollution, block monsoon storm drains, foster vector-borne epidemics, and impose severe occupational hazards on municipal conservancy workers. 

This project presents **EcoTrack — Smart Waste Management and Segregation System**, an open-source, full-stack civic technology platform engineered to bridge the gap between conscientious citizens and municipal sanitation authorities. Developed as an engineering mini-project under the University of Mumbai curriculum for Open Source Software Development, EcoTrack leverages a modern, accessible, and completely cost-free open-source software stack comprising Python with Flask, SQLite, SQLAlchemy ORM, Leaflet.js with OpenStreetMap, Chart.js, and Bootstrap 5.

The application allows registered citizens to report localized garbage hotspots with rich context, including categorical classification across five standard streams (Wet, Dry, Plastic, E-waste, and Mixed/Other), physical landmarks, interactive Leaflet GPS pin-drop coordinates, and photographic evidence verified through safe server-side image processing. Municipal administrators are equipped with a dedicated console to filter, inspect, and transition report statuses from initial triage to verified ground resolution, supported by an immutable activity audit log. An educational waste segregation guide informs citizens about color-coded disposal rules and municipal adaptability.

The system's reliability, input security, CSRF protection, and role-based access control are validated through a comprehensive automated test suite implemented with `pytest` and Flask test client, achieving 100% test pass rates across 34 test scenarios. EcoTrack demonstrates how lightweight open-source software architecture can drive transparent urban civic governance and promote sustainable solid waste recovery.
